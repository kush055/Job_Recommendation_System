# Job Recommendation System

An intelligent, animated web application that recommends jobs based on resume content using OCR, NLP, and machine learning.

---

## Features

- Creative and animated UI (HTML, CSS, JS)
- Resume upload and OCR extraction (PDF, image)
- NLP-powered skill and experience matching
- Admin job posting panel
- PostgreSQL backend for performance and scalability
- User authentication and registration system

---

## Tech Stack

- *Backend*: Django 4.x, Python 3.10+
- *Database*: PostgreSQL
- *OCR*: Tesseract via pytesseract
- *NLP & ML*: nltk, scikit-learn, spaCy
- *Frontend*: HTML5, CSS3, JS, Animate.css, Font Awesome
- *Others*: Pillow, pdfplumber, python-docx, psycopg2-binary
